# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付统计，以及交付归档与复核重开。

## 交付归档与复核重开

- **交付归档**：样本交付时生成不可变归档快照（深拷贝）和归档版本号，落入 `archives`；已归档样本的切片与日志不可再改（接口返回 `409 sample_archived_readonly`）。
- **复核重开**：负责人填写必填原因后，可将已归档样本重开为新版本（版本号 +1）。旧版本快照原样保留只读；工作副本的切片状态回到“退回”，从退回状态继续制片旧流程。
- **并发与过期**：写操作进程内串行化，同一版本并发重开只有一次成功，重复请求返回 `409` 且不改变数据；请求携带 `expectedVersion`，版本不匹配的过期请求返回 `409 stale_reopen_request`。
- **展示**：卡片显示当前版本、归档版本列表（含交付时间、重开原因、负责人）。
- **持久化**：数据保存在 `data/core-slices.json`（tmp+rename 原子写入），重启后归档与版本仍在。
